# Security Policy

## Supported Versions

Images follow [`pyngrok`'s supported versions](https://github.com/alexdlaird/pyngrok/blob/main/SECURITY.md): the newest
image of each supported `pyngrok` version is supported.

## Reporting a Vulnerability

If you suspect you have found a security vulnerability, in an image or in `pyngrok` itself,
[open a report](https://github.com/alexdlaird/pyngrok/security/advisories/new). Please include a clear and concise
description of what the vulnerability is, which image tag it affects, and (if known) what best practices might apply
to patching it.

If the issue is confirmed, a patched image will be released as soon as possible.
